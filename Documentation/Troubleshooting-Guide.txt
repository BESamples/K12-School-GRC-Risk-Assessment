# Northstar Active Directory Lab Troubleshooting Guide

## Purpose

This guide documents problems encountered while deploying the Northstar Active Directory lab on Windows Server 2019.

The purpose is to show how deployment errors were identified, corrected, tested, and documented.

---

## Issue 1: PowerShell Script Execution Was Blocked

### Error

```text
File cannot be loaded because running scripts is disabled on this system.
UnauthorizedAccess
Cause
The Windows Server PowerShell execution policy did not allow unsigned PowerShell scripts to run.

Resolution
PowerShell was opened as Administrator, and the execution policy was temporarily changed for the current PowerShell session:

Set-ExecutionPolicy Bypass -Scope Process -Force
The script was then run again:

& 'C:\Users\Administrator\Downloads\setup-NorthstarAD-Corrected.ps1'
Result
The script was allowed to run.

Security Note
Using -Scope Process limits the change to the current PowerShell session. The server-wide execution policy was not permanently changed.

Issue 2: Northstar Organizational Unit Was Not Found
Error
Get-ADOrganizationalUnit : Directory object not found
ADIdentityNotFoundException
Cause
The original script attempted to locate the Northstar organizational unit using:

Get-ADOrganizationalUnit -Identity $distinguishedName
During the first deployment, the Northstar OU did not exist yet. The -Identity parameter generated an error instead of returning an empty result.

Resolution
The OU lookup was changed to search the parent path:

$existing = Get-ADOrganizationalUnit `
    -Filter "Name -eq '$Name'" `
    -SearchBase $Path `
    -SearchScope OneLevel `
    -ErrorAction Stop
The script then checks whether a matching OU was found:

if ($null -eq $existing) {
    New-ADOrganizationalUnit `
        -Name $Name `
        -Path $Path `
        -ProtectedFromAccidentalDeletion $false |
        Out-Null
}
Result
The script successfully created the Northstar OU and its child OUs.

Issue 3: Unexpected Closing Parenthesis or Brace
Error
Unexpected token ')' in expression or statement.
Unexpected token '}' in expression or statement.
ParserError
Cause
While replacing the Ensure-OU function, parts of the previous function remained in the script.

This created extra closing parentheses and braces around approximately lines 55 and 74.

Resolution
Instead of continuing to edit the damaged copy, a clean corrected version of the script was created.

The corrected script was saved as:

setup-NorthstarAD-Corrected.ps1
The new script replaced the incomplete function sections and ensured that each function had correctly matched parentheses and braces.

Syntax Validation
The following PowerShell command can be used to check the script for syntax errors before running it:

$path = 'C:\Users\Administrator\Downloads\setup-NorthstarAD-Corrected.ps1'

$tokens = $null
$errors = $null

[System.Management.Automation.Language.Parser]::ParseFile(
    $path,
    [ref]$tokens,
    [ref]$errors
) | Out-Null

if ($errors.Count -eq 0) {
    Write-Host 'No syntax errors found.' -ForegroundColor Green
}
else {
    $errors |
        Select-Object Message,
            @{Name='Line'; Expression={$_.Extent.StartLineNumber}},
            @{Name='Column'; Expression={$_.Extent.StartColumnNumber}} |
        Format-Table -AutoSize
}
Result
The corrected script passed syntax validation and completed successfully.

Issue 4: Password Does Not Meet Domain Requirements
Possible Error
The password does not meet the password policy requirements.
Cause
The temporary password entered during setup does not meet the Active Directory domain password policy.

The domain may require:

A minimum password length

Uppercase letters

Lowercase letters

Numbers

Special characters

Resolution
Run the script again and enter a stronger temporary password.

Example format:

Northstar-Lab2026!
Do not store or publish the actual lab password in GitHub.

Issue 5: Script Is Run from the Wrong File Location
Possible Error
The term is not recognized as the name of a cmdlet, function, script file, or operable program.
Cause
PowerShell cannot find the script at the specified path.

This can also happen when multiple copies exist with names such as:

setup-NorthstarAD.ps1
setup-NorthstarAD (1).ps1
setup-NorthstarAD-Corrected.ps1
Resolution
Confirm the script location:

Get-ChildItem 'C:\Users\Administrator\Downloads' |
    Where-Object { $_.Name -like '*NorthstarAD*' }
Run the corrected file using its full path:

& 'C:\Users\Administrator\Downloads\setup-NorthstarAD-Corrected.ps1'
Issue 6: Active Directory Module Is Missing
Possible Error
The specified module 'ActiveDirectory' was not loaded.
Cause
The Active Directory PowerShell module is not installed, or the script is being run on a system without the required management tools.

Verification
Get-Module -ListAvailable ActiveDirectory
Resolution
On Windows Server, install the Active Directory management tools:

Install-WindowsFeature RSAT-AD-PowerShell
Then import the module:

Import-Module ActiveDirectory

Run as administrator
