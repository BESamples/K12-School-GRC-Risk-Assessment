# K-12 School GRC Risk Assessment

## Project Overview

This project is a simulated Governance, Risk, and Compliance assessment for a fictional K-12 school environment.

The purpose of the project is to demonstrate how a GRC analyst can identify cybersecurity risks, evaluate security controls, collect technical evidence, document findings, and create a remediation plan.

The assessment uses a fictional school named Northstar High School. All users, records, systems, and security incidents used in this project are simulated. No real student, employee, or organizational information is included.

## Project Objectives

The objectives of this project are to:

* Identify systems that store or process sensitive school information.
* Create an inventory of systems and information assets.
* Perform a cybersecurity risk assessment.
* Map selected controls to the NIST Cybersecurity Framework and NIST SP 800-53.
* Test security controls in a simulated Windows and Wazuh lab.
* Collect and organize audit evidence.
* Document security findings and recommendations.
* Create a Plan of Action and Milestones.
* Simulate an incident-response exercise.
* Present results in both technical and management-friendly formats.

## Simulated Environment

The simulated school environment includes:

* One Windows Server 2019 domain controller
* One Windows 10 administrative workstation
* One Windows 10 teacher workstation
* One Ubuntu Wazuh server
* One Kali Linux testing system
* Active Directory
* Sysmon
* Wazuh File Integrity Monitoring
* PowerShell logging
* YARA malware detection
* Simulated student and employee records

## Frameworks and Standards

This project will use:

* NIST Cybersecurity Framework
* NIST SP 800-53 security controls
* NIST SP 800-30 risk-assessment concepts
* FERPA-related student data-protection considerations

## Project Deliverables

The completed project will include:

* Project charter
* Assessment scope
* Asset inventory
* Data classification standard
* Risk register
* Risk heat map
* Security control matrix
* Control-testing procedures
* Audit evidence index
* Security findings
* Plan of Action and Milestones
* Incident-response simulation
* Executive summary
* Final assessment report

## Disclaimer

This project is for educational and portfolio purposes only. It represents a fictional school environment and does not constitute a formal compliance audit or legal determination.
