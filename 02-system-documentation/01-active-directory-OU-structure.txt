Service Account Decision

An Active Directory account named svc_wazuh was initially created for the Wazuh service.

The account was removed because the Wazuh manager will run on an Ubuntu virtual machine and does not require an Active Directory service account for normal operation.

This change reduced the number of unnecessary accounts in the domain.
